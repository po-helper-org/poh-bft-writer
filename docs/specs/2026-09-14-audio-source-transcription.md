# Спецификация: запись встречи как источник `/bft-fast` (локальная транскрибация)

**Дата:** 2026-09-14
**Ветка:** `feat/session-status-and-bft-workspace`
**Источник требований:** PO — «была встреча с заказчиком в офлайн, я всё записал на диктофон айфона. Там подробно описаны все пожелания и требования для БФТ. Не могу эту запись напрямую прикрепить или указать ссылку на файл — нужно сначала самому где-то провести транскрибацию»

## Зачем

`/bft-fast` принимал источник только текстом: `#summary`-заметка, файл транскрипта, инлайн, задача Backlog.md. Самый богатый источник требований — живая встреча с заказчиком — в конвейер не попадал: PO сначала искал, где распознать запись, вставлял результат руками, и только потом запускал стенографиста. Лишний ручной шаг между встречей и письмом, и именно тот, о котором забывают.

Периметр `/bft-fast` при этом ломать нельзя: «сам наружу не ходит» — принцип 1 SKILL и гейт 19. Облачные STT-сервисы отпадают по построению: запись встречи с заказчиком не должна покидать машину PO.

## Что решает спека

Запись встречи становится **полноправной формой источника**: `/bft-fast <путь к .m4a> [epic_slug]` (или вложение файла в чат — это тот же путь). Стенографист распознаёт речь локально, показывает путь к транскрипту и дальше идёт по нему как по обычному транскрипту — выжимка до `#summary`, письмо, csv, документ, страница ревью, форки.

### HowToDemo

1. PO запускает `/bft-fast <путь к записи>` — или прикрепляет файл к сообщению с командой.
2. Команда по расширению определяет, что источник — запись (`.m4a`, `.mp3`, `.wav`, `.ogg`, `.opus`, `.flac`, `.aac`, `.mp4`, `.mov`, `.webm` и др.), а не текст.
3. Запись транскрибируется локально: `bft-transcribe.py` → `ffmpeg` (16 кГц моно WAV) → `whisper-cli` (whisper.cpp, модель `large-v3-turbo` из кэша `~/.cache/whisper-cpp`). В чат — строка `Транскрипт: <путь> (запись …, длительность, модель)`. Несколько частей одной записи — несколько транскриптов, по порядку.
4. Транскрипт используется как источник для генерации: он же «источник Summary» в открытом поле документа и `--source` гейта 19 (`bft-ground-lint.py`), цитаты в `requirements.csv` — из него, без таймстемпов.
5. Документ `<epic_slug>-fast.md`, письмо, csv и страница ревью собираются штатно.

### Границы

- **Локально, синхронно.** Распознавание — шаг Этапа 2, не форк: без транскрипта нет источника, ждать всё равно придётся. Час записи на M-серии Mac — минуты.
- **Наружу — только модель.** Единственное обращение в сеть — разовая загрузка `ggml-<модель>.bin` с Hugging Face в кэш; `--no-download` её запрещает (модель кладётся руками). Сама запись машину не покидает.
- **Не эмулировать.** Скрипт упал (нет `ffmpeg`/`whisper-cli`, нет модели, речь не распознана) — прогон останавливается с причиной из stderr. Письмо «по памяти о встрече» не пишется — это та же галлюцинация, что выдуманный департамент.
- **Не диаризация.** Транскрипт не размечает говорящих: `ФИО` в `personas.csv` — только те, кого участники назвали вслух; иначе `[роль не подтверждена]`. Диаризация — отдельная задача, если понадобится.
- **Не Summary.** Скрипт отдаёт сырой текст; выжимку делает стенографист (логика навыка `summary`), как для любого транскрипта.

## Реализация

| Что | Где |
|---|---|
| Скрипт транскрибации, коды выхода 2/3/4/5 | `skills/bft-writer/scripts/bft-transcribe.py` |
| Самотест конвейера (стаб `whisper-cli`, модель не тянется) | `skills/bft-writer/scripts/test-bft-transcribe.sh` |
| Ручная команда | `commands/bft-transcribe.md` (в `COMMANDS` `install.sh`) |
| `/bft-fast`: форма источника, Этап 2, пункт 18 самопроверки | `commands/bft-fast.md` |
| Навык (харнесс читает только его) | `skills/bft-fast/SKILL.md` §resolve-source, §Резолв конфига, §Границы |
| Конфиг `transcribe_model` / `transcribe_language` | `bft-config.template.md` |
| Установка `brew install ffmpeg whisper-cpp` | `README.md`, `docs/guides/quickstart-generate-bft.md` |

Формат транскрипта — markdown с frontmatter (`source_audio`, `duration`, `model`, `language`, `transcribed`, `tool`) и текстом, строка = сегмент распознавания. Служебные строки whisper (`[BLANK_AUDIO]`) отфильтрованы. Дефолтное имя — `<имя записи>.transcript.md` рядом с записью; `--out` — файл или каталог.
