# В публичный репозиторий утекли реальные адреса, ключи задач и имена

## Ситуация

Аудит организации нашёл в публичном репозитории реальные формы внутренних адресов трекера и
вики, ключи задач, идентификаторы страниц, ключ пространства, локальные пути и имена людей в
golden-примерах; установочный однострочник содержал флаг отключения проверки сертификата при
загрузке.

## Причина

Примеры и тесты писались с живых документов и конфигураций; адреса и идентификаторы со временем
оказались зашиты не только в тексты, но и в код линтеров и экспортёров.

## Решение

- Реальные формы ссылок, ключи задач, идентификаторы страниц и локальные пути заменены
  заглушками (`example.com`, вымышленные ключи, `SPACE`); имена людей в golden-примерах —
  вымышленные.
- Флаг отключения проверки сертификата снят из установочного однострочника.
- **Поведенческое изменение**: базовые адреса трекера и вики больше не зашиты в код — читаются
  из переменных окружения, по умолчанию заглушки. Для боевого использования переменные надо
  задать, иначе линтер считает корректными только ссылки на заглушку.
- Проверка чистоты — греп по всем former-паттернам; история git не переписывалась (старые
  значения остаются в старых коммитах).

## Как проверить

Греп-развёртка по рабочему дереву: домен компании, префиксы ключей задач, ключ пространства,
прежние идентификаторы страниц, имена из примеров и `curl -k` — пусто:

```bash
git grep -n "curl -k" && echo LEAK || echo clean
```

Плюс полные суиты тестов: результаты те же, что до правок.

## Уроки

- Публичный репозиторий = утечка по умолчанию: живые адреса и идентификаторы попадают в примеры
  незаметно, аудит регулярный.
- Адреса, зашитые в код, мигрируют в проверки: при обезличивании выносить в переменные
  окружения и явно документировать поведенческое изменение для владельца.
- Снятие `curl -k` — часть гигиены: отключение проверки сертификата в установщике приучает.
- История git остаётся носителем старых значений: переписывание истории — отдельное решение,
  не часть обезличивания рабочих файлов.
