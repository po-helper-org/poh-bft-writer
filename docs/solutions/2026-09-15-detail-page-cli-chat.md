# Правки документа требовали сессии CLI вручную — чат встроили в детальную страницу

## Ситуация

Правки и вопросы по документу требовали отдельно открывать сессию внешнего CLI и переносить
текст туда-обратно; отгрузка в вики из раздела была невозможна.

## Причина

Раздел показывал документ, но не имел канала диалога с агентом; среда для отгрузки (инструменты
вики и трекера) в чате харнесса не настроена.

## Решение

Чат по требованию на детальной странице через внешний CLI:

- Узел запускает CLI с потоковым форматом вывода из рабочего пространства чатов; черновик в
  stdin, поток → события; сессия известна до запуска, продолжаемая сессия подхватывается.
  Правка владельца к deep-документу всегда уходит под командой глубокой стадии.
- Черновик передачи несёт формат итога и блок среды для отгрузки и глубокой стадии (инструменты
  ищутся через поиск инструментов с ожиданием; значения настроек из ответов владельца пишутся в
  корневой конфиг).
- **PATH дописывается при спавне CLI**: под службой запуска шлюз MCP не стартовал и «инструментов
  не было», хотя в терминале всё работало — у службы своё окружение. Конфиг пути и аргументов
  вынесен в настройки.
- Доска сверяется после каждого хода CLI; задача получает ссылки на эпик и страницу; стадия —
  глубокая готовность.
- Копия конфига в рабочем пространстве чатов перечитывается из корневого на каждый ход.
- Браузер: транскрипт с потоком, плёнка проработки поверх документа, тихое перечитывание по
  завершении хода, итог со ссылками и открытыми вопросами.

Попутно (незакоммиченная работа того же дерева): стадии «нуждается в интервью» / «добавлено в
OKR» / «отменено», диалог добавления в OKR, транскрибация записи встречи как источник быстрой
стадии.

## Как проверить

```bash
pnpm test
bash plugin/test-contract.sh
```

Живой харнесс: правка fast-документа — поток, анимация, автообновление, итог в формате,
повторное открытие подхватывает транскрипт; отгрузка — сухой прогон с живыми инструментами,
вопросы в чат, ответ в ту же сессию.

## Уроки

- Сервисы запуска (launchd) не наследуют пользовательский PATH — путь дополняется при спавне
  процесса, иначе «инструментов нет» при работающем терминале.
- Черновик передачи — носитель контракта с агентом: формат итога и блок среды живут в нём, а не
  в памяти собеседника.
- Диалог правок и отгрузка — один канал: после хода перечитывать и документ, и доску.
