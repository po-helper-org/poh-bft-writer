# Корневые пути к ресурсам не разрешались ни в одной раскладке установки

## Ситуация

Установщик кладёт команды и навыки сиблингами под один корень агента; корня `skills/` в
воркспейсе нет — корневые ссылки из команд на ресурсы навыков не разрешались ни в одной из пяти
раскладок. Вместе с этим всплыли ещё два дефекта функциональной валидации: мягкий источник
превращался в точные значения («сутки подойдут, не принципиально» → «SLA 24 часа»), а служебные
пометки правил утекали в тело документа.

## Причина

Инструкции писались из расчёта на структуру репозитория, а не установленной раскладки; гейт
измеримости давил на модель, и она дотягивала мягкие формулировки до точных; валидация тела
документа шла «общим впечатлением», а не построчно.

## Решение

- Пути разведены на три формы: doc-ссылка из команды, doc-ссылка на соседний навык, запуск
  скрипта (cwd шелла — корень воркспейса, плоская замена ломала вызовы линтеров). Введён ключ
  `skills_path` с автодетектом; приёмка «установить dry-run × 5 раскладок» закреплена постоянным
  линтером путей.
- Правило «не выдумывать точность» внедрено во все четыре слоя + машинная проверка в
  grounding-линтере: гейт 19 уже держит источник — величины, чисел которых в источнике нет,
  ловятся тем же проходом.
- Утечка служебных пометок закрыта построчным кодом линтера; линтер сразу нашёл ту же утечку в
  эталоне — пометка правила в теле раздела рисков.

## Как проверить

```bash
python3 skills/bft-writer/scripts/bft-paths-lint.py
bash skills/bft-writer/scripts/test-bft-lint.sh
```

Плюс свежий клон → установка → прогон линтеров из установленной раскладки.

## Уроки

- Инструкции для агента пишутся из расчёта на установленную раскладку, а не на структуру репо;
  раскладки дешёво фиксируются линтером путей по каждой из них.
- Гейт, требующий измеримости, провоцирует выдумывание точности из мягких формулировок —
  закрывать машинной сверкой с источником, а не доверять самоотчёту.
- Построчный обход ловит утечки служебных пометок, которые «общее впечатление» пропускает; новый
  линтер стоит сразу гонять по эталонам — утечка часто уже там.
