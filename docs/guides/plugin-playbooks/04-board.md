# 4. Доска по стадиям

Увидеть весь пайплайн БФТ целиком — включая завершённые и отменённые, которых нет в
очереди панели.

## Шаги

### 1. Открой доску

Внизу панели «Требования» нажми **«Открыть доску требований»**. Доска занимает весь
экран: семь колонок в порядке пайплайна, у каждой — счётчик.

```
To Do → NEED-CUSTDEV → FAST-DONE → DEEP-REVIEW → DEEP-DONE → OKR-ADDED → BFT-CANCELED
```

![Доска: семь колонок по стадиям](screenshots/04-board/01-board.png)

Пустые колонки тоже показываются — с нулём. Так видно, где пайплайн пуст, а не только
где есть работа.

### 2. Открой карточку

Нажми карточку — откроется детальная страница этого требования (сценарий 3). **«Назад»**
на ней вернёт на доску, а не в список.

### 3. Заведи инициативу

**«Добавить»** в правом углу шапки открывает форму сбора инициативы на всю страницу.
Кнопка активна, только если в настройках задана ссылка на форму — иначе она погашена, а
подсказка по наведению говорит, где её задать. Подробности — сценарий 6.

![«Добавить» в шапке доски](screenshots/04-board/02-add.png)

### 4. Передай готовый БФТ в OKR

У карточек в колонке **DEEP-DONE** есть кнопка **«Добавить в OKR»**. Она открывает окно:
ссылки на Confluence и эпик уже подставлены (обязательны, можно поправить), выбери
**квартал** (`2026-Q4`, …), заполни **планирование** — спринт и плановые ресурсы по фазам
`RESEARCH / ANALYZE / DEV / QA / RELEASE`, команды исполнения, ответственных техлидов и
исполнителей — и, если нужно, свободный комментарий. **«Добавить в OKR»** записывает всё в
задачу Backlog.md (`--plan`, `--append-notes`, `--add-ref`) и переводит её в `OKR-ADDED` —
карточка уезжает в соседнюю колонку. Поля планирования те же, что на карточке KR в
разделе «Управление целями», формат блока совпадает.

Кнопка есть только у `DEEP-DONE`: из `OKR-ADDED` повторная передача невозможна — план
там уже могли править в OKR.

### 5. Вернись к списку

Стрелка **«←»** в шапке доски возвращает панель к очереди.

## Что стоит знать

- Доска грузит список сама при каждом открытии — она не зависит от того, что успела
  загрузить панель. Кэш браузера общий, поэтому первая отрисовка мгновенная.
- Колонки не сжимаются под узкий экран: если их не вместить, доска скроллится по
  горизонтали целиком.
