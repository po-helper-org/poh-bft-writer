# Система БФТ-требований

**Превращает запрос заказчика в выверенный документ бизнес-функциональных
требований** — с зафиксированными договорённостями и границами исполнителей.

!!! note "Как читать документацию"
    Выберите свою роль ниже — каждый раздел ведёт по шагам
    от «что я вижу» до «что я получаю».

## Ваши разделы

- **[:material-handshake: Для заказчиков](customers/index.md)** — как ваш запрос
  становится инициативой на доске, где отвечать на вопросы и что вы получаете в конце.
- **[:material-compass: Для PO](po/index.md)** — ввод требований, fast-скоринг
  за минуту, запуск проработки, решения и приёмка пакета.
- **[:material-tools: Для сотрудников](employees/index.md)** — задачи верификации
  в трекере: что подтверждать, как закрыть задачу, чтобы конвейер продолжился.
- **[:material-cog: Администрирование](admin/index.md)** — подъём системы,
  ключи, доступы, мониторинг, обновление.

## Что такое конвейер БФТ

Каждая инициатива проходит один и тот же путь — и всегда видна на доске:

```
ЗАПРОС ──▶ СБОР ──▶ ВЕРИФИКАЦИЯ ──▶ VALIDATED
человек    ИИ-агент  диалоги людей   контракт для команды
написал    собрал    зафиксированы   исполнителей готов
                     договорённости
```

## С кем вы взаимодействуете

| Роль | Где работает | Что делает |
|---|---|---|
| Заказчик | чат-комната (Element) | формулирует запрос, подтверждает границы |
| PO | веб-интерфейс системы | вводит требование, принимает решения |
| Сотрудники | трекер задач | подтверждают свою часть требований |

!!! tip "Обещание системы"
    Ни одна договорённость не теряется: каждое «да» и каждый открытый вопрос
    живут задачей со статусом, а молчание само получает напоминание.
