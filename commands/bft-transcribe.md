## Использование

```
/bft-transcribe <запись> [<запись> ...] [--out <файл|каталог>] [--model <имя>] [--language <код>]
```

**Параметры:**
- `<запись>` — путь к аудио/видео-файлу (вложение чата — это тоже путь). Несколько записей одной встречи (диктофон разбил на части) — перечислить по порядку; на каждую будет свой транскрипт.
- `--out` — куда положить транскрипт: файл для одной записи, каталог для нескольких. Не задан → `<имя записи>.transcript.md` рядом с записью.
- `--model` — модель whisper.cpp: `large-v3-turbo` (дефолт, лучший для русской речи), `medium`, `small`, `base`; или путь к `.bin`. Берётся из `transcribe_model` в `bft-config.md`, если задан.
- `--language` — язык речи, дефолт `ru`; `auto` — автоопределение. Берётся из `transcribe_language` в `bft-config.md`, если задан.

## Примеры

```
/bft-transcribe ~/Downloads/Встреча\ с\ заказчиком.m4a
/bft-transcribe part1.m4a part2.m4a --out .bft/documentation/lk-b2b/
```

## Что делает

Обычно вызывать не нужно: `/bft-fast <запись>` сам распознаёт аудио-источник этим же скриптом и идёт дальше к письму. Команда — ручной путь: получить транскрипт отдельно (прочитать глазами до генерации, отдать коллеге, склеить с заметками), пересобрать его другой моделью или после падения авто-шага.

Скрипт `bft-transcribe.py` конвертирует запись через `ffmpeg` в 16 кГц моно WAV и распознаёт её `whisper-cli` (whisper.cpp) **локально**. Наружу уходит только разовая загрузка модели ggml с Hugging Face в кэш `~/.cache/whisper-cpp` (`$WHISPER_CPP_MODEL_DIR`); сама запись машину не покидает — периметр `/bft-fast` («сам наружу не ходит») сохранён. Результат — markdown с frontmatter (`source_audio`, `duration`, `model`, `language`, `transcribed`) и текстом без таймстемпов: строка = сегмент распознавания. Транскрипт — сырой текст встречи, не Summary: выжимку до `#summary` делает уже `/bft-fast` (Этап 2).

**Установка (один раз):** `brew install ffmpeg whisper-cpp`. Модель скачивается при первом прогоне (`large-v3-turbo` — ~1,6 ГБ; на M-серии Mac час записи распознаётся за несколько минут). Без сети — положить `ggml-<имя>.bin` в кэш руками и запускать с `--no-download`.

## Инструкция для LLM

1. Резолв `skills_path` и опц. `transcribe_model`/`transcribe_language` из `bft-config.md` (нет файла — дефолты скрипта).
2. Выполнить:

   ```bash
   python3 <skills_path>/bft-writer/scripts/bft-transcribe.py <запись> [<запись> ...] [--out …] [--model …] [--language …]
   ```

3. Код 0 — вывести строки `Транскрипт: <путь> (…)` из stdout скрипта и предложить следующий шаг: `/bft-fast <путь к транскрипту> [epic_slug]`.
4. Ненулевой код — процитировать причину из stderr (`⚠️ Транскрибация не выполнена: …`) и остановиться. Коды: 2 — файл/формат, 3 — нет `ffmpeg`/`whisper-cli` (подсказать `brew install ffmpeg whisper-cpp`), 4 — модель недоступна, 5 — распознавание упало или речь не найдена. Содержимое записи **не эмулировать** и текст «по памяти» не придумывать: транскрипта нет — нет и источника.
