## Использование
```
/bft-deep <документ|epic_slug|seed> [epic_slug]
```
- `<документ|epic_slug|seed>` — приоритет источника (`orchestration.md` §Стадии, стадия 1): путь к существующему документу БФТ; либо `epic_slug`, если документ уже лежит по стандартному пути `<docs_path>/<epic_slug>/<epic_slug>.md` или опубликован (тогда читается `confluence_get_page` по `pageId`); документа нет нигде → деградация на seed (Fast-черновик/Summary), сначала собрать шапку по `document_assembly.md`.
- `[epic_slug]` — опц.; нужен в основном при seed-деградации (без него — date-slug из темы); при чтении существующего документа epic_slug берётся из его frontmatter/пути.

## Важно
Роль — Обогатитель (V2). Берёт основу, наращивает глубину, укладывает в канон-структуру MTS. Стоп на валидированном черновике; `/bft-deliver` — отдельный ручной шаг PO. Факт без источника → `[УТОЧНИТЬ]`. Шапка `bft-fast` сохраняется дословно, канон дописывается ниже строки-границы. Обновляется та же Confluence-страница по `pageId`, дубль не создаётся.

## Инструкция для LLM
1. Загрузить `skills/bft-deep-swarm/SKILL.md` + resources (orchestration/enrichment/grounding_verifier/eval_rubric).
2. Резолв конфига (SKILL.md §Резолв).
3. Прочитать документ БФТ и зафиксировать границу шапки (`orchestration.md` стадия 1: приоритет источника, поиск границы по порядку якорей `document_assembly.md`). Затем прогнать оркестрацию `resources/orchestration.md` стадии 0-11 (стадия context — `/bft-index`; если индекс `.bft/index/` устарел или неполон по теме, перезапустить `/bft-index` перед этой стадией).
4. Emit (`orchestration.md` стадия 11): собрать документ = замороженная шапка (байт-в-байт) + канон MTS вместо плейсхолдера `## ⏳ Полный БФТ — в проработке`; обновить frontmatter (`stage: deep`, `version`+1, `synced`, `status`) и строку-статус; сохранить `<docs_path>/<epic_slug>/<epic_slug>.md` + artefacts/. Опубликовать: сухой прогон превью → STOP → «ок» PO → `confluence_update_page` по `pageId` из frontmatter (не создавать новую страницу; `pageId: pending` → предложить публикацию как новую страницу тем же сухим прогоном). MCP недоступен → `[УТОЧНИТЬ: MCP недоступен]`, локальный файл сохранён. Нотификация — успех/провал, никогда молча.
