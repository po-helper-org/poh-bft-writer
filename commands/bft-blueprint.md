## Использование

```
/bft-blueprint <epic_slug|путь> [вводная] [--story | --map | --layers]
```

**Параметры:**
- `<epic_slug|путь>` — слаг эпика (БФТ ищется по пути `<docs_path>/<epic_slug>/<epic_slug>.md`, если его нет — `<epic_slug>-fast.md` с предупреждением) либо прямой путь к документу.
- `--story` — опц., только первый этап: собрать или пересобрать историю и остановиться.
- `--map` — опц., только второй этап по уже согласованной истории.
- `--layers` — опц., прежняя слоевая схема `<epic_slug>-blueprint.md` для документов, собранных раньше.
- `[вводная]` — опц., текст или путь к файлу: какие команды участвуют и кто что делает. Без неё команды берутся из «Зависимостей» БФТ, остальное — `[УТОЧНИТЬ]`.

## Примеры

```
/bft-blueprint bartello-restart
/bft-blueprint bartello-restart --story
/bft-blueprint bartello-restart --map "сканер делает Bartello, проверку билета — GDS"
```

## Что делает

**Этап 1 — история через экраны**, со своей паузой:

1. `<epic_slug>-story.md` — персонажи, этапы, шаги, экраны, вопросы.
2. `<epic_slug>-story.html` — каждый персонаж — ряд, который читается слева направо через экраны; карточка шага — картинка, контур, заголовок, пояснение; «Рассказать историю по шагам» — слайды; красная точка — открытый вопрос.

Пробелы истории агент закрывает сам: один раунд до четырёх вопросов PO с вариантами из БФТ.

**Этап 2 — карта инициативы**, когда PO согласовал историю:

1. `<epic_slug>-blueprint/` — проект [Backlog.md](https://github.com/MrLesk/Backlog.md), его агент ведёт CLI `backlog`. Задачи «Что делаем»: исполнитель — команда, метка этапа, постановка ASIS, GAP, TOBE, HowToDemo, критерии приемки. Их подзадачи «Как это работает»: метка слоя, суть, «Параметры» IDEF0, схема mermaid, HowToDemo, ссылки. Документы: «Карта» (команды, вопросы), «История», требования к экранам.
2. `<epic_slug>-map.html` — собирается из проекта скриптом. Первый экран на всю высоту — «Что видят» раскадровкой; «Что делаем» и «Как это работает» — свои экраны, переключатель рядом с меню, этапы закреплены сверху. «Как это работает» — четыре ряда: Employee Actions, Technology, Backstage, Support, стрелки — из ссылок в параметрах. Клик по карточке — суть, параметры, IDEF0, HowToDemo, вопросы, ссылки. Клик по задаче — «Требования» и «Исполнение» (JIRA, Confluence, заметка → команда `backlog task edit`). Клик по кадру — требования к экрану для дизайнера. Правой кнопкой по любой секции — замечание, в меню «Замечания» — промпт для агента. Один файл без CDN; на телефоне — лента по шагам.
3. `<epic_slug>-blueprint.zip` — автономный проект: папка Backlog.md, страница `blueprint.html`, скрипты и правила в `.blueprint/`. Распаковал — `backlog board`, правки агентом, пересборка `python3 .blueprint/scripts/bft-backlog-build.py . --out-dir .`

## Важно

**Не источник требований.** Только то, что есть в БФТ или в ответах PO. Нет — `[УТОЧНИТЬ у {кого}]` и строка в «Вопросах».

**Лёгкая карта, детали по клику.** Задача — одна строка до 80 знаков, ряды — слои Service Blueprint, а не системы. Эндпоинты, протоколы, таблицы и поля — вне высоты БФТ, линтер их отклоняет.

**Каждое ФТ, ИТ и НФТ на карте** — в задаче или карточке.

**Бэклог — источник, страница — сборка.** Агент исследует БФТ и раскладывает его в задачи и документы Backlog.md через CLI; IDEF0 карточки (mermaid), страница и архив собираются из файлов детерминированно, без ИИ.

**Не входит в контур по умолчанию.** `/bft-fast` и `/bft-deep` команду не вызывают — только явный запуск.

**Не трогает БФТ.** Единственные записи — `<epic_slug>-story.*`, проект `<epic_slug>-blueprint/`, `<epic_slug>-map.html` и `<epic_slug>-blueprint.zip` (в режиме `--layers` — `<epic_slug>-blueprint.md`, `.html`, `.svg`).

## Инструкция для LLM

Навык — `../skills/bft-blueprint/SKILL.md`. Порядок — этапы оттуда: resolve → **story** со своим STOP → **map** → STOP. Стандарты — `resources/story_line.md`, `resources/story_interview.md`, `resources/backlog_rules.md`; эталоны — `examples/golden_story.md`, проект `examples/bartello-restart-blueprint/`.

### Гейт перед показом PO (обязателен)

История:

```bash
python3 <skills_path>/bft-blueprint/scripts/bft-story-lint.py <docs_path>/<epic_slug>/<epic_slug>-story.md
python3 <skills_path>/bft-writer/scripts/bft-style-lint.py <docs_path>/<epic_slug>/<epic_slug>-story.md
python3 <skills_path>/bft-blueprint/scripts/bft-story-render.py <docs_path>/<epic_slug>/<epic_slug>-story.md
```

Карта:

```bash
python3 <skills_path>/bft-blueprint/scripts/bft-backlog-init.py <docs_path>/<epic_slug>/<epic_slug>-story.md   # один раз: проект Backlog.md
python3 <skills_path>/bft-blueprint/scripts/bft-backlog-lint.py <docs_path>/<epic_slug>/<epic_slug>-blueprint --source <docs_path>/<epic_slug>/<epic_slug>.md
python3 <skills_path>/bft-blueprint/scripts/bft-backlog-build.py <docs_path>/<epic_slug>/<epic_slug>-blueprint --source <docs_path>/<epic_slug>/<epic_slug>.md
```

Ненулевой код — причина в выводе, исправить через `backlog task edit` или `backlog doc update` и прогнать снова. Сборка по сломанному проекту файлов не пишет.

### САМОПРОВЕРКА ИСТОРИИ

1. Каждый персонаж — ряд «Знакомьтесь» → шаги → «И с тех пор», слева направо?
2. Карточка шага — только картинка, контур, заголовок, пояснение?
3. Ни ID требований, ни команд, ни слов разработки в истории (нет `ST012`)?
4. У каждого шага и экрана есть источник (нет `ST016`)?
5. Вопросы PO заданы одним раундом, с вариантами из БФТ; без ответа — красная точка?
6. На STOP показаны путь к `-story.html`, «было → стало» и вопросы «кому — что»; карта не начата, пока PO не согласовал историю?

### САМОПРОВЕРКА КАРТЫ

1. Колонки и «Что видят» совпадают с согласованной историей?
2. Задача — один результат одной команды до 80 знаков, без API и БД (нет `BL014`, `BL018`)?
3. Каждое ФТ, ИТ, НФТ есть в задаче или карточке (нет `BL017`)?
4. У каждой задачи есть постановка (зачем, ASIS, GAP, TOBE, HowToDemo) и критерии приемки, исполнитель — команда или метки `кандидат:…`?
5. У каждой задачи есть карточка «Как это работает» в своём слое; у карточки — суть, «Параметры» с выходом, HowToDemo и связь с другой карточкой (нет `BL021`, `BL023`, `BL028`)?
6. Неизвестное — в «Вопросах» документа «Карта» с «Кому» и «Где»; блокеры отмечены типом `блокер`?
7. У каждого экрана истории есть документ «F3 · …» в `screens/` с тремя вкладками, Functions — сценарии с **Тогда**, без `SN0xx`?
8. Задачи и документы созданы CLI `backlog`, сборка дала `<epic_slug>-map.html` и `<epic_slug>-blueprint.zip`?
9. На STOP показаны пути к странице и архиву, задачи по командам, блокеры и вопросы «кому — что»?
