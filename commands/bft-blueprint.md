## Использование

```
/bft-blueprint <epic_slug|путь> [вводная] [--story]
```

**Параметры:**
- `<epic_slug|путь>` — слаг эпика (БФТ ищется по пути `<docs_path>/<epic_slug>/<epic_slug>.md`, если его нет — `<epic_slug>-fast.md` с предупреждением) либо прямой путь к документу.
- `--story` — опц., только первый этап: собрать или пересобрать историю через экраны и остановиться.
- `[вводная]` — опц., текст или путь к файлу: какие системы и команды участвуют, кто что отдаёт. Без неё дорожки берутся из «Зависимостей» БФТ, остальное — `[УТОЧНИТЬ]`.

## Примеры

```
/bft-blueprint direct-faq
/bft-blueprint bartello-restart --story
/bft-blueprint direct-faq "витрина и Direct — команда Разработка, поиск — внешний"
/bft-blueprint .bft/documentation/direct-faq/direct-faq.md
```

## Что делает

Сначала — **история через экраны** (верхняя линия blueprint), отдельным этапом со своей паузой:

1. `<epic_slug>-story.md` — персонажи, этапы, шаги, экраны, вопросы.
2. `<epic_slug>-story.html` — страница истории: каждый персонаж — ряд, который читается слева направо через экраны; карточка шага — картинка, контур (витрина, письмо, SMS, приложение), заголовок, пояснение; клик — подробности и источник в БФТ; «Рассказать историю по шагам» — слайды; красная точка — открытый вопрос.

Пробелы истории агент закрывает сам: один раунд до четырёх вопросов PO с вариантами из БФТ. История согласована — дальше слои. Рядом с БФТ появляются ещё три файла:

1. `<epic_slug>-blueprint.md` — источник правды: образ результата, стадии, дорожки, карточки, связи.
2. `<epic_slug>-blueprint.html` — страница ревью: диаграмма, «что реализовать на каждом слое» по дорожкам, покрытие каждого ФТ/ИТ/НФТ карточками, список нерешённого. Один файл, без CDN.
3. `<epic_slug>-blueprint.svg` — та же диаграмма картинкой для Confluence.

На диаграмме колонки — стадии пути клиента, строки — слои: выгода клиента → действия → точки контакта │ витрина │ сервисы (дорожка на систему или команду) │ основа. Пунктирные линии отделяют то, что видит клиент, от того, что он не видит. Карточка несёт статус работы (`создать`, `доработать`, `используем`, `уточнить`) и ссылки на требования БФТ.

## Важно

**Не источник требований.** Рисует только то, что есть в БФТ. Нет в БФТ — карточка `уточнить` с `[УТОЧНИТЬ у {кого}]` и вопрос в чат.

**Общая картина, не проработка.** Карточка до 100 знаков, не больше 25 карточек. Эндпоинты, протоколы, таблицы и поля — вне высоты БФТ, линтер их отклоняет.

**Не входит в контур по умолчанию.** `/bft-fast` и `/bft-deep` команду не вызывают — только явный запуск.

**Не трогает БФТ.** Единственные записи — `<epic_slug>-story.*` и `<epic_slug>-blueprint.*`.

## Инструкция для LLM

Навык — `../skills/bft-blueprint/SKILL.md`. Порядок работы — этапы 1–8 оттуда (resolve → **story** со своим STOP → image → stages → lanes → cards → emit → STOP). Этап story — по `resources/story_line.md` и `resources/story_interview.md`, эталон — `examples/golden_story.md`.

### Гейт перед показом PO (обязателен)

История (этап 2):


Слои (этап 7):


### САМОПРОВЕРКА ИСТОРИИ (этап 2)

1. Каждый персонаж — ряд «Знакомьтесь» → шаги → «И с тех пор», слева направо?
2. Карточка шага — только картинка, контур, заголовок, пояснение (плюс номер и красная точка)?
3. Ни ID требований, ни команд, ни слов разработки в истории (нет `ST012`)?
4. У каждого шага и экрана есть источник в БФТ или ответ на вопрос (нет `ST016`)?
5. Вопросы PO заданы одним раундом, с вариантами из БФТ; без ответа — красная точка, а не догадка?
6. На STOP показаны путь к `-story.html`, «было → стало» по персонажам и открытые вопросы «кому — что»; слои не начаты, пока PO не согласовал историю?

### САМОПРОВЕРКА ПЕРЕД ВЫВОДОМ

1. БФТ (`<epic_slug>.md`, `-fast.md`, csv, карта контекста) не изменён?
2. «Образ результата» — три строки, каждая из текста БФТ?
3. Каждое ФТ, ИТ, НФТ БФТ стоит хотя бы на одной карточке (линтер без `BP012`)?
4. В карточках нет эндпоинтов, протоколов, таблиц и полей (`BP013`)?
5. Каждое число и срок на карточке есть в БФТ (нет `BP018`)?
6. Каждая дорожка — система или команда из «Зависимостей» или вводной PO, не выдумка?
7. В итоге для PO названо, что должна отдать каждая дорожка, и перечислены все `[УТОЧНИТЬ]` списком «кому — что»?
