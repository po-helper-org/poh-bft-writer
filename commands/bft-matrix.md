## Использование

```
/bft-matrix <epic_slug> [вводная]
/bft-matrix <epic_slug> --status EX-NN <статус> ["причина"]
```

**Параметры:**
- `<epic_slug>` — эпик. Матрица собирается **только по deep-БФТ** `<docs_path>/<epic_slug>/<epic_slug>.md`
  (`stage: deep`). Есть только `-fast.md` — команда останавливается и предлагает `/bft-deep`: по шапке
  инициатива неполна, и трассировка бесполезна.
- `[вводная]` — текст или путь к файлу: итоги встречи-старта, список команд, кто кому что отдаёт,
  сроки. Без вводной команды и сроки берутся из «Зависимостей» БФТ, остальное — `[УТОЧНИТЬ]`.
- `--status EX-NN <статус>` — `сдано`, `принято`, `возврат`, `в работе`, `заблокировано <чем>`,
  `n/a <причина>`. Возврат пишет запись в журнал возвратов.

## Примеры

```
/bft-matrix direct-faq
/bft-matrix direct-faq итоги-старта-15-10.md
/bft-matrix direct-faq --status EX-02 возврат "выложили на dev, на test не видно"
/bft-matrix direct-faq --status EX-02 принято
```

## Что делает

Собирает `<epic_slug>-matrix.md` и страницу `<epic_slug>-matrix.html` рядом с БФТ. В матрице:

1. **Участники** — команды, представители на стыках, руководители, зрелость и режим чеклиста.
2. **Покрытие требований** — каждое ФТ, ИТ, НФТ БФТ и команды, которые обязаны его закрыть.
3. **Карта стыков** — кто кому что отдаёт.
4. **Матрица исполнения** — строки EX-NN: поставщик (команда и человек), потребитель, что, где,
   критерий приёмки, доказательство, проверяющий из другой команды, пауза, срок, статус.
5. **Чеклисты точек паузы** — старт, стыковка, приёмка, запуск, после запуска.
6. **Журнал возвратов** — где ошиблись, тип, корневая причина, урок.
7. **Риски стыков** — только подтверждённые PO.

Страница — тот же инструмент, что у БФТ: выделил текст мышью → комментарий → промт для ИИ
(«Доработай матрицу исполнения …», с адресом строки `· EX-NN`). Сверху — сводка исполнения по
командам: сколько строк принято, в работе, заблокировано, сколько возвратов; клик по команде
оставляет в матрице её строки. Требования ФТ-N ведут на страницу БФТ. Кнопка «Всё ок —
отгружай матрицу в Confluence» кладёт в буфер `/bft-deliver <epic_slug> --matrix`.

## Инструкция для LLM

Прочитай `../skills/bft-exec-matrix/SKILL.md` и выполни его режим по аргументам: сборка — этапы
1–8, `--status` — §«Статус строки». Проверка перед показом PO обязательна:

```bash
python3 <skills_path>/bft-writer/scripts/bft-matrix-lint.py <docs_path>/<epic_slug>/<epic_slug>-matrix.md
python3 <skills_path>/bft-writer/scripts/bft-style-lint.py <docs_path>/<epic_slug>/<epic_slug>-matrix.md
python3 <skills_path>/bft-writer/scripts/bft-html-export.py <docs_path>/<epic_slug>/<epic_slug>-matrix.md
```

Ненулевой код линтера — исправить и прогнать снова. После — STOP: путь к странице и вопросы по
`[УТОЧНИТЬ]` списком «кому — что».
