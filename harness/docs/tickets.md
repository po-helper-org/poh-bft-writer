# Тикеты: автономная система БФТ (harness/)

Спека: `specs/2026-10-23-harness-ui-mode.md` (46 story) · ADR 0001–0006 ·
components.md. Тикет-трассер: каждый — сквозной результат с проверяемым
критерием готовности. Порядок работы — по blocking-рёбрам; полосы А/Б/В,
гейты А4, Б4(част.), В7. Локальный трекер: правки статуса прямо здесь
(`[ ]` → `[x]`, дата).

## Полоса А · Каркас (риск: dsh в Docker не проверен апстримом)

### Т1 · Вендор коробки `[x] 2026-10-23`
Перенести `poh-bft-box` в `box/` (код, тесты, Dockerfile), NOTICE о
происхождении, перенести его ADR в `box/docs/adr/` с пометкой. Прогнать
28 контрактных эталонов.
**Готово:** `cd box && python -m pytest tests/` зелёный; `git log` — один
merge-коммит вендора.
Blockers: —

### Т2 · Контейнер харнесса + compose-каркас `[~] 2026-10-23`
Авторинг готов: `harness/harness-web/Dockerfile` (3 стадии: плагин pnpm →
профиль npm 6 плагинов пин 0.1.7-rc.2 → рантайм), `entrypoint.sh` (факт
апстрима: `--host` отвергает wildcard — биндим IP контейнера + `--public-url`),
`profile/package.json.in` + `cordis.patch.yml`, `docker-compose.yml`
(5 сервисов default + debug/demo профили; 8700 наружу не публикуем).
**Блокер верификации:** на машине нет Docker (нет sudo) — гейт требует
Docker Desktop / OrbStack / CI / целевой сервер.
**Готово:** `docker compose up -d` — healthchecks зелёные, панель монтируется.
Dockerfile `harness-web` (мульти-стадия: сборка плагина → профиль 6 плагинов →
dsh web), `docker-compose.yml`: harness-web, box-mcp, box-worker, temporal,
postgres (лимиты памяти из ADR-0006, минимум 6 ГБ). DSH_HOME и workspace —
volumes. Порты: только 3080 наружу.
**Готово:** `docker compose up -d` поднимает 5+1 сервисов, все healthchecks
зелёные, панель плагина монтируется в UI (маркер в бандле).
Blockers: Т1

### Т3 · start.sh + install.sh-режимы `[~] 2026-10-23`
Авторинг готов: start.sh (--demo/--debug/--no-open, генерация POSTGRES_PASSWORD/
BOX_TOKENS, ожидание health, ссылка с токеном из логов → `.last-url`, open),
install.sh — шаг «UI | CLI | оба» с подсказкой `cd harness && ./start.sh`,
`.env.example`, `update.sh`.
**Блокер:** тот же (Docker-рантайм) для живого прогона.
**Готово:** на чистой машине `./harness/start.sh` без ручных правок `.env`
печатает рабочую ссылку.
start.sh: генерация POSTGRES_PASSWORD/BOX_TOKENS при первом запуске,
`compose up`, ожидание health, извлечение `?token=` из логов, печать + запись
`.last-url`, открытие браузера. install.sh: шаг «UI | CLI». `.env.example`.
**Готово:** на чистой машине `./harness/start.sh` без ручных правок `.env`
печатает рабочую ссылку.
Blockers: Т2

### Т4 · acceptance.sh — ГЕЙТ ПОЛОСЫ А `[ ]`
S3-шов: healthchecks, токен-ссылка, `/api/board` пусто-норма, demo-профиль
smoke (`scripts/smoke.py`), маркер панели, лимиты RAM не превышены.
**Готово:** `./harness/acceptance.sh` exit 0 на чистом подъёме и после
рестарта (состояние переживает рестарт — US-27).
Blockers: Т3

## Полоса Б · Люди

### Т5 · Чистое ядро плагина (S2) `[ ]`
`contacts:` из frontmatter (роли/отсутствие→открытый вопрос), модель карточек
указаний (типы исполнителей, статусы диалога), слияние стадия⊕состояние для
доски и конвейер-режима. Только чистые функции, `node --test`.
**Готово:** новые тесты зелёные без I/O.
Blockers: Т4

### Т6 · Онбординг `[ ]`
5 слайдов, Z.AI-ключ → host-API → `harness/.env`, «Проверить» (тест-вызов),
переключатель диктовки (браузерная/локальная), «Пропустить» с предупреждением,
флаг в settings.
**Готово:** первый запуск US-5–8; после записи ключа рестарт поднимает
провайдера zai.
Blockers: Т4

### Т7 · Интейк + upload-API `[ ]`
Дефолтный экран: строка ввода, Web Speech/MediaRecorder по переключателю,
`POST attachments` → `workspace/uploads/<ts>-<slug>/`, ссылки-чипы.
**Готово:** US-9–13 руками; файлы появляются в воркспейсе.
Blockers: Т4

### Т8 · Мини-чат fast + запуск проработки `[ ]`
Сессия dsh со скиллом `bft-fast` (glm-5-turbo) в воркспейсе БФТ; карточка
результата: скоринг, контакты, источники, открытые вопросы; кнопка
«Запустить проработку» → `POST /api/start`.
**Готово:** US-14–18; от ввода до карточки ≤ 1 мин на реальном ключе.
Blockers: Т5, Т7

## Полоса В · Процесс

### Т9 · Конвейерные состояния коробки `[x] 2026-10-23`
Реализовано проекцией (не переименованием): `box/bftbox/stage.py` —
`stage` (request/drafting/verifying/validated) + `waiting_for` (роли открытых
указаний) в `list`/`board`/`card`; контракт 1.0.0 не тронут.
**Готово:** 47 тестов зелёные (28 эталонов без правок); `/api/board` отдаёт
доменные стадии.
Blockers: Т1

### Т10 · Трекер `[ ]`
Vikunja в compose (общий postgres, LAN-порт 3456), сид квартальных проектов,
лейблы `bft:<slug>`, типы задач, вебхук → Коробка, аккаунты сотрудников.
**Готово:** US-19–20, 41; закрытие задачи человеком продолжает воркфлоу.
Blockers: Т9

### Т11 · Шлюз Matrix `[ ]`
Synapse (федерация выкл.) + Element Web в compose (:8008/:8090), секреты в
start.sh, matrix-nio в box-worker: комната `#bft-<slug>`, аккаунт заказчика,
приглашение, слушатель ответов → `submit`.
**Готово:** US-35–40, 43–45; диалог с живым заказчиком в Element фиксируется
договорённостью.
Blockers: Т9

### Т12 · Сценарные активности `[ ]`
Активности воркфлоу: создать задачу/ждать закрытия/напомнить/эскалировать/
диалог-комната; обёртки REST Трекера и Matrix; сессионные задачи-записи.
**Готово:** US-24–25, 38–39; сценарий «спросить→напомнить→эскалировать»
проходит на demo-профиле.
Blockers: Т10, Т11

### Т13 · UI указаний и конвейер `[ ]`
Сайдбар: секция указаний + бейдж; карточки с типами исполнителей и статусом
диалога; кнопки → submit / сессия / статус; конвейер-режим доски (4 колонки)
+ чипы состояний на карточках.
**Готово:** US-19, 21, 24–26; карточка отражает ответ из Трекера и Matrix.
Blockers: Т5, Т12

### Т14 · Детальный экран полного цикла `[ ]`
Полная форма БФТ + таймлайн итераций + светофор + `temporal_url` + ссылки на
комнату и задачи инициативы.
**Готово:** US-22–23, 28, 45.
Blockers: Т13

### Т15 · HOWTODEMO — ГЕЙТ СИСТЕМЫ `[ ]`
`harness/docs/HOWTODEMO.md`: 8 шагов владельца с Matrix-шагом, ручная
приёмка на реальном ключе; прогон полного сценария установка→validated.
**Готово:** свежий человек проходит сценарий по документу без подсказок.
Blockers: Т6, Т8, Т12, Т13, Т14
