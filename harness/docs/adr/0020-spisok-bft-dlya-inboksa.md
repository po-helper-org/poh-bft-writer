# ADR-0020: Список БФТ для Инбокса PO и ссылка на чат заявки

Статус: принято (2026-11-23).

## Контекст

PO ведёт день в Инбоксе (виджет Element): обещания, заметки, созвоны. Заявки
портала БФТ-требований жили отдельно — на странице «Все заявки» за входом
портала. Требование владельца: раздел «БФТ» в Инбоксе — список заявок с кратким
статусом, карточка с артефактами и ссылкой на чат заявки в портале; «+» — портал
для новых требований. В оболочке /sprints — пункт меню «Сервис БФТ».

## Решение

- **`GET /api/customer-form.bftList`** — JSON того же состава, что «Все заявки»:
  на каждую заявку `stage` (dialog → demo → fast-review → fast-approved →
  deep-building | deep-ready | deep-failed), `stageLabel`, колонка трекера,
  `chatUrl`, вопросы формы (всего / отвечено) и артефакты: полный БФТ,
  первичные требования (`&view=fast`), сценарий приёмки, открытая форма вопросов,
  задача трекера (если адрес открывается снаружи); у документов — выгрузка
  .docx/.pdf/.md. Сборка карточки — `bft-list.ts`, без чтения файлов.
- Ссылки — публичные адреса портала (`PORTAL_PUBLIC_URL`), за Authentik, как и
  раньше: Инбокс их не проксирует, а открывает в браузере.
- Читает список сервер Инбокса на этой же машине (127.0.0.1:3082). Снаружи
  маршрут за Authentik — тот же круг, что видит «Все заявки».
- **Чат заявки по ссылке**: `/?session=<id>` открывает эту сессию в портале
  вместо новой (обычный вход по-прежнему заводит свою сессию).

## Последствия

- Инбокс показывает все заявки портала, а не только «свои» браузера.
- Открыть чат по ссылке может любой, кто прошёл вход портала и знает id сессии —
  как и раньше со страницы «Все заявки».
