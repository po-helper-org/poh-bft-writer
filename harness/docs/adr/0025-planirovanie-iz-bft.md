# ADR-0025: «Планирование» — от полного БФТ сразу к декомпозиции

Статус: принято (2026-11-24).

## Контекст

После полного БФТ PO с командой разработки разбирает его на встрече: вопросы,
декомпозиция по ролям, риски, сроки. Записи и схемы жили отдельно (доска
Excalidraw, заметки) и в заявку и Confluence переносились руками.

Требование владельца: на странице БФТ кнопка «Планирование» — экран с текстовой
заметкой (заголовки Вопросы, Декомпозиция, Риски, Сроки) и доской для
миниатюр; «Сохранить» — артефакт внизу БФТ, скачивается .zip; при публикации в
Confluence заметка — текстом комментария, архив и доска (.pdf) — вложениями.

## Решение

- **Экран** `customer-form.plan?session=` — новая вкладка из кнопки на странице
  полного БФТ. Слева — обычная текстовая заметка с заголовками (Tab — отступ,
  Enter продолжает список, Ctrl/⌘+S — сохранить, черновик в браузере до
  сохранения). Справа — Excalidraw 0.18 в духе FigJam: своя нижняя панель
  «Выбор · Рука · Стикер · Текст · Стрелка» (V H S T A), панели Excalidraw
  (свойства, цвета, толщина, меню, библиотека, подсказки) скрыты. Стикер —
  клик по доске: карточка без обводки, сразу ввод текста; стрелки
  цепляются к стикерам. Цвета стикеров как в FigJam — десять пастельных; ряд
  цветов над панелью виден при инструменте «Стикер» или выделенных стикерах:
  клик перекрашивает выделенные и задаёт цвет новых; линии ровные, шрифт Nunito. Автор сохранения — кто
  вошёл в портал (заголовок Authentik), без поля ввода.
- **Доска без CDN.** `customer-form/board/` — отдельный пакет: React и
  Excalidraw собираются esbuild в один `board.js` и `board.css`, шрифты
  (кроме китайского Xiaolai, 12 МБ) встроены data-URL. Портал отдаёт бандл
  маршрутом `customer-form.planAsset` сжатым gzip. Сборка плагина портала
  (tsdown, общий React оболочки) не затронута.
- **Сохранение** `customer-form.planSave` → папка заявки `plan/`: `note.md`,
  `board.excalidraw` (сцена, можно открыть в excalidraw.com), `board.svg`
  (без скриптов), `board.pdf` (WeasyPrint, страница по размеру рисунка) и
  `planirovanie.zip` — заметка и доска .excalidraw (PDF доски — отдельным
  файлом). Заметка из панели меняет `note.md` и, если доска уже есть, архив;
  номер версии растёт только с сохранением доски. ZIP пишет сам
  портал — в образе нет `zip`. Версия растёт с каждым сохранением, в трекер —
  комментарий.
- **Страница БФТ**: вкладка «Планирование» в левой рейке (ADR-0026) открывает
  боковую панель — сначала только заметка, она сохраняется сама
  (`customer-form.planNote`, через ~1 с после ввода и при уходе со страницы).
  Внизу панели — «Перейти на доску» (полный экран заметка + доска); после
  первого сохранения доски — «Скачать архив планирования». Без рейки (нет
  формы вопросов) — по-старому, кнопка под заголовком ведёт на полный экран.
  После сохранения доски внизу документа — блок «Планирование»: когда и кто,
  «Открыть», «Скачать .zip», «Доска .pdf», «Заметка .md» (`customer-form.planFile`).
- **Confluence.** Портал в Confluence не пишет (шлюз источников — только
  чтение); публикует агент своим Atlassian MCP (ADR-0023).
  `bft_export_for_confluence` добавляет блок «Комментарий к странице
  (планирование)» — текст заметки и список вложений; `bft_get_planning_file`
  отдаёт zip и pdf в base64 — агент прикладывает их к странице.

## Последствия

- Образ портала собирает ещё один бандл (~9 МБ, gzip ~2,5 МБ) — +1–2 минуты
  сборки.
- Совместного редактирования нет: один экран — один автор; последнее
  сохранение побеждает, прежние версии не хранятся (номер версии есть).
- Китайские символы на доске рисуются запасным шрифтом браузера.
