# Matrix — единый коммуникационный шлюз внешнего контура

Любая коммуникация ИИ-агента и Коробки с внешним миром проходит через встроенный
Matrix-сервер: сначала Matrix, из него — во внешний контур. Два контура:
**внутренний** (сотрудники — в Трекере, PO — в Харнессе) и **внешний**
(заказчик — в Matrix). Почтовых серверов, SMS-шлюзов и внешних мессенджеров
в коробке нет — локальный Matrix закрывает всё, и коробка остаётся
самодостаточной («поставил, запустил — работает автономно на любом клиенте»).

**Модель:** комната на инициативу `#bft-<slug>`; сценарий создаёт её при
переходе в верификацию, выдаёт заказчику аккаунт и приглашение. Сообщения
пишет сценарий (matrix-nio из box-worker), ответы слушает тот же слушатель:
ответ заказчика → `submit` в конвейер → договорённость зафиксирована. Молчание
N дней → напоминание в комнату → эскалация PO карточкой (таймеры Temporal).
Переписка — контекст инициативы; коммуникационная задача в Трекере отражает
статус диалога.

**Выбор сервера — element-hq/synapse** (официальный, активный; AGPL). Отвергнуты:
dendrite (архив 2024), conduwuit (репозитории архивны/нестабильны). Вес принят:
общий postgres, федерация выключена по умолчанию (закрытый контур). Element Web
раздаётся из коробки как статический сервис — но совместим любой Matrix-клиент:
заказчик может пользоваться своим.

## Considered Options

- PO пересылает ответы заказчика руками (рекомендация R7 до ответа владельца) —
  ручной труд в конвейере на 100+/сутки; владелец выбрал автоматизацию через Matrix.
- Email-шлюз — требует домен, DKIM, борьбу со спам-фильтрами; против коробочности.
- Внешние мессенджеры напрямую (Telegram/WhatsApp API) — каждый свой контракт,
  модерация, лимиты; Matrix даёт один шов, мосты к внешним мессенджерам —
  следующим шагом уже поверх него.

## Consequences

- Compose: +2 сервиса (`matrix` synapse, `element` веб-клиент) → 8 сервисов;
  **минимум RAM поднимается с 4 до 6 ГБ** (правка NFR спеки).
- LAN-порты: `:8008` Matrix client API (для клиентов заказчика), `:8090`
  Element Web; федерация `:8448` закрыта. Харнесс остаётся `127.0.0.1:3080`.
- Инвариант взаимодействий (components.md) уточнён: Коробка ходит в Трекер,
  **Matrix** и z.ai.
- Указания верификации заказчика превращаются из «PO пересылает» в «система
  спросила сама»: карточка указания показывает статус комнаты (отправлено,
  прочитано, ответ получен).
- Мосты Matrix↔email/Telegram — v2, отдельным решением; шов уже готов.
