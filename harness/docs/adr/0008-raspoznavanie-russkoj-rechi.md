# speech-ru: распознавание русской речи для голосового ввода dsh

Микрофон композера (голосовой ввод dsh) на rev9 ADR-0007 распознавал речь
локальным GigaAM. Живая проверка владельца — «Речь не распознана»: в логе
5,4 с записи → 0 символов за 106 мс, то есть детектор речи не нашёл ни одной
фразы. Тихий сигнал причиной не был: GigaAM распознаёт текст даже при −45 дБ.
Скорее всего, в распознаватель пришла пустая запись (браузер пишет не с того
устройства или беззвучный поток), а заказчик увидел ничего не объясняющее
«Речь не распознана».

## Решение

Отдельный dsh-бандл `speech-ru/` регистрирует в `ctx.speechToText` провайдер
`ru-speech` и сам выбирает его по умолчанию. SenseVoice при этом выключается:
русского он не знает. Цепочка в одном провайдере:

1. **Уровень сигнала** — пик WAV ниже −50 дБFS считается тишиной. Заказчик
   видит «микрофон передал тишину. Проверьте, что в браузере и в системе
   выбран нужный микрофон…»; в сеть такая запись не уходит.
2. **Облако** — Requesty `POST /v1/audio/transcriptions`, модель
   `openai/gpt-4o-mini-transcribe`, `language=ru`, `prompt` с терминами
   (БФТ, JIRA, Confluence, 1С, ЗУП, HowToDemo). Ключ — `REQUESTY_API_KEY`,
   тот же, что у модели портала.
3. **Резерв** — GigaAM v3 в `context-ingest` (`POST /transcribe`), если облако
   ответило ошибкой, не уложилось в 20 с, вернуло пустой текст или ключа нет.

`mode: local-only` в конфигурации бандла — только GigaAM, запись не покидает
контур. Реестр dsh сам между провайдерами не переключается, поэтому резерв
живёт внутри провайдера.

| | gpt-4o-mini-transcribe (Requesty) | GigaAM v3 (локально) |
|---|---|---|
| 12 с заметки | 2,4 с, «Привет, это Ирина из отдела кадров…» | 0,8 с, тот же текст |
| В портале (9 с речи) | 1,6 с на сервере, 1,9 с до текста в поле | ≈0,9 с |
| Термины, имена | подсказка `prompt` | нет |
| Запись | уходит в Requesty → OpenAI | остаётся в compose-сети |

Облако — основной путь: так решил владелец; модель держит живую речь,
шум и термины из подсказки. Локальный GigaAM — резерв и режим для
закрытого контура.

## Проверка

- `speech-ru/test` (node --test, без сети, при сборке образа): тишина не
  уходит в сеть; в Requesty передаются `model`, `language=ru`, `prompt`;
  ошибка облака → GigaAM; `local-only` облако не трогает.
- E2E `voice-input.spec.ts`: подставной микрофон Chromium с
  `fixtures/memo.wav` → текст «…из отдела кадров…» в поле ввода.
- E2E `voice-silence.spec.ts`: подставной микрофон с `fixtures/silence.wav`
  → «микрофон передал тишину».

## Не закрыто

- Запись микрофона — до 120 с (ограничение API голосового ввода dsh).
- Файлы встреч (rev8 ADR-0007) по-прежнему расшифровывает GigaAM: нужны
  метки времени `[мм:сс]` и длинные записи. Перевести их на
  gpt-4o-transcribe — отдельное решение (лимит 25 МБ, нарезка).
