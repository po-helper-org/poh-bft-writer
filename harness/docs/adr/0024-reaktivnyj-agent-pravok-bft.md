# ADR-0024: Реактивный ИИ-агент правок БФТ — очередь, точечная перерисовка, две модели

Статус: принято (2026-11-24). Развивает ADR-0021; проект — `harness/docs/specs/2026-11-24-bft-agent-reactive.md`.

## Контекст

Агент ADR-0021 принимал пачку замечаний, отдавал модели весь документ (42 КБ, 20–60 с) и
перезагружал страницу. Требование владельца: одно обращение — одна обработка, без ожидания и
перерисовки всего документа; быстрая модель для локальных правок; полное ревью
согласованности — отдельной кнопкой и полной моделью, подключение моделей — в настройках.
Замеры: lint 145 мс, экспорт страницы 330 мс, проверки портала < 100 мс — узкое место модель.

## Решение

- **Очередь** (`bft-revise.ts`, `index.ts`): каждое замечание — задача `revise` (`queued →
  writing → checking → ready/failed`) в `revisions.json`. Исполнитель один на заявку, задачи по
  порядку: каждая ложится на результат предыдущей. Очередь переживает рестарт (её подхватывает
  запрос статуса); новые замечания можно слать, пока агент работает.
- **Локальная правка**: модель получает только раздел замечания (по заголовку из «Комментариев»,
  иначе — раздел с цитатой или ID строки; не нашлось — весь документ) и оглавление. Фрагмент
  «найти» ищется и должен быть уникален в этом разделе. Проверки шаблона — по всему документу
  относительно исходного, как раньше.
- **Модели** (`models.json`, «Настройки → Портал»): «локальные правки» — по умолчанию Haiku
  (`requesty / anthropic/claude-haiku-5-5`), не ответила — модель полного БФТ; «полное ревью» —
  агент полного ревью (`review-agent.ts`), если настроен в окружении, иначе модель полного БФТ.
- **Агент полного ревью** — внешний агент без инструментов через шлюз агентов (Responses API).
  Портал ходит в него по точному nginx `location = /bft-review/v1/responses` (только POST одного
  метода, ставит `install-nginx-bft.sh`, адрес агента — `BFT_REVIEW_AGENT_UPSTREAM` в окружении
  сервера). Ключ — `BFT_REVIEW_AGENT_KEY`, кладёт владелец (`set-review-agent-key.sh`). Без
  инструментов — потому что в документе текст заказчика (prompt injection).
- **Точечная перерисовка** (`doc-sections.ts`): страница ревью собирается целиком, затем
  сравнивается с прежней по разделам `<main>` (h2 или свёрнутый `details.fold`). В задаче —
  `sections`; страница забирает HTML только этих разделов (`bftReviseSection`) и заменяет их на
  месте с подсветкой, без перезагрузки и прыжка прокрутки. Поменялся состав разделов —
  перезагрузка, как раньше. Скрипт страницы ревью даёт `window.bftReview.refresh(rev)`:
  точки «УТОЧНИТЬ», оглавление, счётчики; внесённые замечания закрывает агент по `ref`,
  неотправленные остаются открытыми.
- **Полное ревью**: светящаяся точка у «Комментариев», пока после последнего ревью есть внесённые
  локальные правки → «Проведите полное ревью требований для согласованности» → «Отправить» →
  задача `review` в ту же очередь: весь документ + список локальных правок с прошлого ревью.
- **Откат любой правки**: последняя изменившая документ — по копии; поверх легли другие —
  обратной заменой её вставок, если они с тех пор не менялись (удаление из середины не
  откатывается).

## Последствия

- Замечание правится за секунды, документ меняется по ходу очереди; 10 замечаний ≈ минута.
- Haiku слабее на канонических таблицах: сломанный шаблон — второй круг, затем отказ без
  изменений; полное ревью добирает сквозную согласованность.
- Без агента полного ревью (нет адреса или ключа) ревью делает модель полного БФТ.
- **Закончился баланс** (HTTP 402 или текст провайдера об оплате): провайдер помечается на
  10 минут — правки сразу идут на запасную модель, в карточке пометка «У … закончился баланс —
  правила запасная модель …»; сборка полного БФТ падает с понятной ошибкой; в «Настройки →
  Портал» — предупреждение. Баланс кончился и у запасной — правка отказывает тем же текстом,
  документ не тронут. «Сохранить» в настройках снимает пометку.
- **Без кнопок и имени** (24.11): новое замечание со страницы уходит агенту сразу; лежавшие до
  открытия страницы — кнопкой «Отправить ИИ-агенту» в «Комментариях», рядом осталась
  «Скопировать промт». Имя в журнал не спрашиваем. «Настройки» в шапке колонки — вход
  администратора → «Настройки → Портал»; там же подключение к шлюзу агентов (адрес с профилем,
  ключ — только на запись, хранится в томе узла) и выбор агента для локальных правок и ревью.
