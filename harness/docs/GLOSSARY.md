# Глоссарий poh-bft-writer (UI-контур, harness/)

Словарь единого репозитория после объединения с poh-bft-box. Термины CLI-контура
(`/bft-*`, стадии документа) наследуются без изменений; здесь — то, что появилось
с автономным UI-режимом. Конфликт с глоссарием box — ошибка: правьте оба места.

| Термин | Определение |
|---|---|
| **UI-режим** | Автономная система из `harness/`: `docker compose up -d` поднимает DeepSeek Harness, коробку и Temporal. Не требует IDE-агента. |
| **CLI-режим** | Прежний контур: `install.sh` синкает команды и навыки в корень IDE-агента (Claude Code, Codex, …). Не требует Docker. |
| **Интейк** | Первый экран UI-режима: форма ввода требования (текст, голос, файлы, фото, PDF, ссылки) и мини-чат на быстрой модели. |
| **Быстрый прогон (fast)** | Прогон скилла `bft-fast` в сессии харнесса по вводным интейка: фиксация первичных требований, письмо, `personas.csv`, `requirements.csv`, документ-шапка. Цель — не глубина, а точная фиксация сказанного. |
| **Процесс** | Temporal-workflow коробки: детерминированный владелец жизненного цикла инициативы — итерации, таймеры, ожидания людей, ретраи. Переживает рестарты. |
| **Сессия** | Чат харнесса (dsh). Расходный исполнитель: живёт, пока идёт ход агента; процесс не зависит от её судьбы. |
| **Указание** | Единица работы процесса, адресованная человеку или агенту: `approve_plan`, `decide`, «согласовать», «ответить». В UI видна как карточка действия; ответ уходит `submit`. |
| **Инициатива** | Сущность коробки: требование, запущенное в процесс (`/api/start`). Связана со слагом документа БФТ. |
| **Стадия** | Положение требования на доске девяти стадий (`To Do` → … → `BFT-CANCELED`). Выводится из артефактов документа и/или доски Backlog.md. |
| **Состояние процесса** | Фаза инициативы внутри коробки (`preparing`, `working`, `waiting_po`, `accepted`, …). Не путать со стадией документа. |
| **Конвейер** | Доменные состояния инициативы в Коробке: запрос → сбор → верификация → validated (ADR-0005). Не колонки Трекера и не стадии документа. |
| **Сбор** | Состояние конвейера: ИИ-агент + методология poh-bft-writer превращают вводные в документ БФТ (fast → deep, светофор). |
| **Верификация** | Состояние конвейера: диалоги с сотрудниками, PO-руководителями, заказчиками; каждое требование подтверждается, договорённость фиксируется. Ожидания расщеплены по адресатам. |
| **Validated** | Требования собраны и описаны; договорённости зафиксированы; границы исполнителей прописаны; открытые вопросы перечислены явно. Готовый БФТ — контракт для этапа системных требований. |
| **Трекер** | Vikunja — накопитель задач 4 типов и контекста; зеркало, не источник истины (ADR-0004). Пишут коробка, агенты, сотрудники. |
| **Сессионная задача** | Запись агентной сессии в Трекере (ссылка, итог) — накопление контекста по инициативе. |
| **Шлюз** | Matrix-сервер коробки: единственный путь коммуникаций ИИ-агентов во внешний контур (ADR-0006). |
| **Комната инициативы** | Matrix-комната `#bft-<slug>`: переписка с заказчиком, контекст верификации. |
| **Внешний контур** | Заказчик и любые внешние люди — работают через Matrix. |
| **Внутренний контур** | Сотрудники — в Трекере, PO — в Харнессе; наружу не ходят. |
| **Коробочность** | Свойство продукта: поставил, запустил — работает автономно на любом клиенте, без внешних зависимостей кроме ключа LLM. |
| **Светофор** | Итог проверок качества пакета БФТ по каталогу `config/checks.json`: зелёный/жёлтый/красный. Зелёный без доказательства — жёлтый. |
| **Провайдер** | LLM-подключение харнесса. В v1 онбординга — только Z.AI (GLM); ключ `ZAI_API_KEY` в `harness/.env`. |
| **Рука** | Исполнитель указания: агентная сессия dsh (скиллы) или сам box-worker (LLM-итерации документа). Мозг (решения, состояния) — всегда коробка. |
| **Сценарий** | Подпись последовательности активностей в воркфлоу коробки для комбинированных цепочек («написать → согласовать → ждать N дней → эскалировать»). Не отдельный слой оркестрации. |
| **Шов** | HTTP-API Коробки (5 эндпоинтов) — единственная точка связи интерактивного и процессного слоёв. MCP отложен до второго реального вызывателя (ADR-0001 rev 2). |

## Не слова этого мира

- «Сессия процесса» — оксюморон: процесс не сессия. Если нужно назвать связку —
  «указание и его исполнитель».
- «Оркестрация в харнессе» — харнесс интерактивен, оркестрации в нём нет и не будет;
  последовательности живут в Temporal.
