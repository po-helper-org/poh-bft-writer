### How to demo

1. Открываю в Direct карточку события (потом площадки, потом персоны) → есть раздел «Вопрос-ответ».
2. Добавляю вопрос, правлю, меняю порядок, один скрываю.
3. Захожу на страницу на сайте → вижу опубликованные вопросы; скрытый не показан.
4. На странице без вопросов блока нет, страница работает как обычно.
5. Проверяю в Google Search Console / Яндекс.Вебмастер, что вопросы попали в поиск (в течение суток обновится).

### Сценарий приёмки (happy path + alt)

```plantuml
@startuml
autonumber
actor "Контент-менеджер" as CM
participant "Карточка в Direct" as Direct
participant "Страница на сайте" as Site
actor "Посетитель сайта" as Visitor
participant "Поисковая система" as Search
activate Direct
CM -> Direct: открывает карточку события (площадки, персоны)
Direct -> Direct: раздел «Вопрос-ответ» — добавить, отредактировать, переставить порядок
CM -> Direct: скрывает один вопрос
Direct -> Site: изменения уходят в топик публикации
deactivate Direct
activate Site
Visitor -> Site: открывает страницу события, площадки или персоны
alt Вопросов нет
  Site --> Visitor: блока «Вопрос-ответ» на странице нет, страница работает как обычно
else Есть опубликованные вопросы
  Site --> Visitor: видит опубликованные вопросы, скрытый не показан
end
Site -> Search: опубликованные вопросы доступны для индексации
deactivate Site
activate Search
CM -> Search: проверяет Google Search Console / Яндекс.Вебмастер
Search --> CM: вопросы в поисковой выдаче (обновление — в течение суток)
deactivate Search
@enduml
```

Атрибутивный состав сообщений (параметры и типы запросов/ответов) не входит в БФТ — зона СА / системных требований.
