## Гипотеза проблемы

| Блок | Формулировка | Источник |
|---|---|---|
| Person | Оператор колл-центра | personas.csv: «Оператор колл-центра» |
| Problem | Переспрашивает адрес дважды | гипотеза ← [ASIS не озвучен] · requirements.csv |
| Motivation | Хочет закрывать заявку в одном разговоре | |

**Метрика:** доля заявок, закрытых с первого звонка
**Проблема понижает метрику:** оператор уходит на второй звонок

## Цели интервью

1. Проверить, что оператор действительно перезванивает
2. Выяснить, чем меряют долю повторных звонков ← метрика цели не задана
