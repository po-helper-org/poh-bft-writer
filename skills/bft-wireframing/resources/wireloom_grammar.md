# Грамматика Wireloom для экрана БФТ

Только то, что реально нужно для раскадровки сценария БФТ. Полная грамматика
(game-UI примитивы: `grid`/`chart`/`resourcebar`/`stats`/`tree`/`menubar` и
прочее) — в `AGENTS.md` самого пакета Wireloom (`node_modules/wireloom` после
`npm install` в `../scripts/wireloom-runtime/`); нужен нетипичный виджет —
смотреть туда.

## Каркас экрана

Каждый вызов рендера — **один `window` на источник** (ограничение самого
Wireloom, не наше): `window:` без заголовка, если экран уже подписан своей
рамкой браузера/телефона — заголовок окна тогда дублирует подпись кадра.

**Веб (browser):**
```wireloom
window:
  navbar:
    leading:
      text "Название системы" bold
    trailing:
      text "Режим: …" muted
  row:
    col 190:
      list:
        slot "Раздел 1"
        slot "Раздел 2" active
        slot "Раздел 3"
    col:
      panel:
        text "Заголовок экрана" bold size=large
        divider
        ...содержимое...
  footer:
    kv "Решение" "…" bold accent=success
```

**Мобильный (mobile):** списки экранов — `header large:` + `list` + `tabbar`
внизу; переход в детали — `navbar` с `leading: backbutton "Назад"` и, если
нужно, `trailing:` с действием.

```wireloom
window:
  header large:
    text "Заголовок списка"
  list:
    slot "Строка" chevron:
      kv "Поле" "значение"
  tabbar:
    tabitem "Раздел 1" selected
    tabitem "Раздел 2"
```

## Примитивы

| Примитив | Для чего в БФТ | Заметка |
|---|---|---|
| `window` | корень, ровно один на кадр | заголовок часто лучше опустить (см. выше) |
| `navbar` (веб) / `header large` (моб.) | шапка экрана | `navbar` — прямой потомок только `window`, взаимоисключим с `header` (одно из двух на экран) |
| `row` / `col N` / `col` (fill) | раскладка навигация+контент | `col 190:` — фиксированная ширина, голое `col:` — тянется |
| `list` + `slot "Название"` | пункт навигации, строка токена/пула, карточка в журнале | `slot` без `:` — просто пункт списка (леф без детей — валиден) |
| `slot "…" active` / `chevron` | подсветить текущий раздел / пометить «есть переход в детали» | `active` — то же, что `selected` для `tabitem` |
| `panel` / `section "Заголовок"` | контентная область, группа полей | `section` умеет `badge="…"` |
| `kv "Метка" "Значение"` | строка поле-значение (сумма, комиссия, решение) | `bold`, `accent=success\|danger\|warning` — для акцента на числе/решении |
| `text "…"` | заголовок, статус, пояснение | `muted`, `bold`, `size=large`, `accent=` |
| `radio` / `checkbox` / `toggle` | режимы, настройки | `label-right` — контрол слева, подпись справа (обычный вид настроек) |
| `button "…"` | действие | `primary` — акцентная кнопка |
| `divider` | разделитель внутри панели | — |
| `footer` | итоговая строка/решение внизу экрана | **только прямой потомок `window` или `slot`** — см. ловушку ниже |
| `tabbar` + `tabitem` (моб.) | нижняя навигация | `selected`, опц. `icon=`, `badge=` |
| `navbar` + `backbutton` (моб.) | переход назад с деталей | `leading: backbutton "Откуда"` |

## Три ловушки (пойманы на практике, не в документации проекта)

1. **`footer` — только прямой потомок `window` или `slot`.** Внутри `col`/`panel` — ошибка разбора («footer may only appear directly inside window or slot»). Строку решения/итога поднимай на уровень `window` (полоса на весь экран снизу), а не прячь внутрь панели.
2. **Несколько `text` в одном `footer` не встают друг под другом** — рендерятся внахлёст на одной строке. Если нужна пара «метка + акцентное значение» — `kv "Решение" "ДОПУСТИТЬ" bold accent=success` в один вызов, не два `text`.
3. **У `panel`/`window` нет атрибута ширины.** Ширина считается по самому длинному `kv`/содержимому; длинный `text` в футере обрезается по правому краю, если контент выше уже. Держи футер-текст короче остального содержимого экрана, а не наоборот.

## Заземление (обязательно)

Любое число или статус на кадре — либо цитата уже одобренного ФТ/НФТ/примера
ТЗ, либо `—`/пусто. `kv "Прибыль" "0.33 GRAM"` — можно, если 0.33 GRAM уже
где-то в документе как пример; `kv "Прибыль" "0.41 GRAM"` без такого примера —
уже придуманное число, даже если выглядит правдоподобно.
