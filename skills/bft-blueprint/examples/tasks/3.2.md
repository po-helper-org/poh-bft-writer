## ASIS
Список обрезан радиусом, фильтров нет.

## GAP
Гость не может быстро найти ресторан под свою компанию рядом с театром.

## TOBE
«Все рестораны» показывает полный список участников с фильтрами: персоны, животные, средний чек, метро, кухня.

## HowToDemo
1. Открываю «Все рестораны» — вижу полный список
2. Фильтрую по персонам, животным, чеку, метро, кухне
3. Открываю карточку ресторана

## Чеклист приемки
- [ ] Полный список, не обрезан радиусом
- [ ] Работают все пять фильтров
- [ ] Метрики по каждому фильтру
- [ ] Пустой результат фильтров согласован с PO
