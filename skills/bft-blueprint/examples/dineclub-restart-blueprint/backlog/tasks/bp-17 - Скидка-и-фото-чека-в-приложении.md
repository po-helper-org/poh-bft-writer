## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Гость получает обещанное — цель пути достигнута

Требования БФТ: ПТ-1, ИТ-8, ФТ-8

### ASIS
Скидка давалась только по брони.

### GAP
Гость с билетом без брони не получает обещанную скидку.

### TOBE
Официант даёт скидку 10% по предъявлению билета без брони и после оплаты фотографирует чек в приложении.

### HowToDemo
1. Гость показывает действующий билет
2. Официант даёт скидку 10% без брони
3. После оплаты фотографирует чек — компенсация зафиксирована
