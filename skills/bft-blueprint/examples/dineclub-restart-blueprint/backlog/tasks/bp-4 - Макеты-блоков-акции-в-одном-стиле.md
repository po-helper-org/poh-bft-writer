## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Один узнаваемый вид акции во всех точках: TY-страница, письмо, карточка, сканер

Требования БФТ: НФТ-4

### ASIS
Блоки акции в разных точках выглядят по-разному, единого макета нет.

### GAP
Гость не узнаёт акцию в разных точках контакта.

### TOBE
Все блоки акции — страница после оплаты, письмо, карточка, сканер — в одной фиолетовой айдентике от одного дизайнера.

### HowToDemo
1. Открываю макеты всех блоков акции
2. Сверяю: страница после оплаты, письмо, список, карточка, сканер — один стиль
3. Сверяю экраны с бордой FigJam

### Дополнительно
- Борда FigJam «Спецпроект Acme Tickets»
