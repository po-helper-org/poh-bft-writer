# Прототипы карты инициативы

Согласованные промежуточные версии формы blueprint. Это эталоны вида, а не сгенерированный вывод навыка: генератор их ещё не собирает.

| Файл | Что зафиксировано |
|---|---|
| `bartello-map-v18.html` | Карта инициативы по БФТ bartello-restart. Шаги пути слева направо; «Что видят» — экран и фраза гостя или ресторана; «Что делаем» — задачи по командам с фильтром по команде; «Как это работает» — Frontstage, Backstage, Support. Клик по экрану — требования, состояния и UserFlow, по задаче — IDEF0. Инструкции, легенда, блокеры, рассказ по шагам. |
| `bartello-map-v20.html` | То же плюс карточка процесса для техлида: «до → этот процесс → после», «было → станет», чек-лист «что требуется» (✓ / уточнить / блокер), sequence-диаграмма с линией видимости и списком скрытых шагов, IDEF0, заметка и промпт для системной аналитики с ИИ. |

Страницы автономные: открывается в браузере без сети.
