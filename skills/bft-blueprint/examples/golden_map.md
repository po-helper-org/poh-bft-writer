## Схемы

```seq П1
описание: Гость покупает билет на оффлайн-мероприятие — страница после оплаты показывает блок «скидка 10%» и полку ресторанов у площадки билета. События блока уходят в аналитику.
G -> V: покупает оффлайн-билет
V -> M: площадка билета
M --> V: рестораны у площадки
V --> G: блок «скидка 10%» и полка ресторанов
V -> An: события блока
G -> V: «Все рестораны»
```

```seq П2
описание: После покупки GDS отправляет письмо с билетом и одним акцентным офером — скидка 10%. Клик ведёт на страницу акционных ресторанов, UTM — в аналитику.
Gd -> Mail: после покупки — письмо с билетом
Mail -> G: один офер — скидка 10%
G -> Mail: клик «Выбрать ресторан»
Mail -> V: переход на страницу акционных ресторанов
Mail -> An: UTM, клики по позициям
```

```seq П3
описание: «Все рестораны» показывает всех участников без обрезки радиусом: ближние и с высоким рейтингом выше, фильтры по персонам, животным, чеку, метро и кухне.
```
