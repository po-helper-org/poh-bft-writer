## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Полка и список показывают только то, что есть в каталоге: пустой каталог — пустая акция

Требования БФТ: ФТ-3, ФТ-4, НФТ-2

### ASIS
Список ресторанов обрезан радиусом; часов работы и рейтинга у части участников нет.

### GAP
Полка и список не могут показать всех участников с рейтингом и часами работы.

### TOBE
Каталог содержит всех ресторанов-участников с рейтингом и часами работы и отдаётся полке, списку и карточке.

### HowToDemo
1. Bartello передаёт список ресторанов-участников
2. Каталог загружает рейтинги из справочника
3. Открываю «Все рестораны» — вижу всех участников с рейтингом и часами работы

### Дополнительно
- Рейтинги — выгрузка Яндекс.Карт, без API
