## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Гость узнаёт о скидке, даже если пропустил блок на TY-странице

Требования БФТ: ПТ-2, ИТ-2, ФТ-5

### ASIS
В письме плашка «забронировать в Bartello» без акцента на скидке.

### GAP
Гость, пропустивший блок на странице после оплаты, не узнаёт о скидке из письма.

### TOBE
Письмо с билетом несёт компактную плашку с одним акцентным офером — скидка 10%; «забронировать в Bartello» — вторичным.

### HowToDemo
1. Открываю письмо с билетом
2. Вижу компактную плашку с одним офером — скидка 10%
3. Нажимаю «Выбрать ресторан» — открывается страница акционных ресторанов
