# Постановка задачи для техлида (task_brief.md)

Ряд «Что делаем» на карте — это бэклог задач, без которых требования БФТ не реализовать. Клик по задаче открывает постановку для техлида: файл `tasks/<ID>.md` рядом с картой, по одному на задачу. Как делать, постановка не расписывает — только что есть, чего не хватает, что должно стать и как это проверить.

## Файл

```md
## ASIS
Механика скидки привязана к брони, проверки билета нет.

## GAP
Без проверки одна покупка может дать несколько скидок или ни одной.

## TOBE
Проверка по штрихкоду: билет активен, не использован, мероприятие было не больше 7 дней назад; успех помечает билет «использован», отказ — с причиной.

## HowToDemo
1. Сканирую действующий билет — проверка пройдена, билет «использован»
2. Сканирую тот же билет снова — отказ «использован»
3. Сканирую билет вне окна 7 дней — отказ с причиной

## Чеклист приемки
- [ ] Проверка: активен, не использован, не больше 7 дней
- [ ] Отказ — с понятной причиной

## Дополнительно
- Ссылки на документы, ограничения, контекст
```

| Раздел | Что писать |
|---|---|
| ASIS | как устроено сейчас — одна-две фразы из «Изменения в UJM» и ASIS БФТ; нет в БФТ — `[УТОЧНИТЬ у {кого}]` |
| GAP | чем текущее не соответствует требованиям — что ломается для человека или бизнеса |
| TOBE | какой станет система после доработки — из ФТ, ИТ, НФТ задачи |
| HowToDemo | E2E-сценарий проверки, нумерованный, от лица пользователя — из How to demo БФТ |
| Чеклист приемки | Definition of Done: короткие проверяемые пункты `- [ ]` — из критериев процессов задачи и НФТ |
| Дополнительно | по желанию: ссылки, ограничения, связанные экраны (`screens/<ID>.md`) |

Требования БФТ задачи и её открытые вопросы и блокеры страница добавляет к «Дополнительно» сама — из карты. В файле их не повторяют.

Заголовок файла не нужен: название задачи, команда и этап берутся из карты. ID в тексте сверяются с БФТ (`MP016`).

## Проверка

`bft-map-lint.py` разбирает папку `tasks/` рядом с картой (`bft_tasks.py`).

| Код | Уровень | Что не так |
|---|---|---|
| TK001 | ошибка | имя файла — не ID задачи карты |
| TK002 | ошибка | раздел не из списка, не по порядку, нет обязательного, текст вне раздела |
| TK003 | ошибка | обязательный раздел пустой |
| TK004 | ошибка | в HowToDemo меньше двух шагов `1. …` |
| TK005 | ошибка | в чеклисте нет пунктов `- [ ] …` |
| TK020 | предупреждение | задача без постановки |

На странице отметки чеклиста сохраняются в браузере.
