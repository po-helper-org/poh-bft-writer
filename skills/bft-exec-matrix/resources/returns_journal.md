# Журнал возвратов и риски стыков (returns_journal.md)

Журнал — главное отличие матрицы от Jira. Jira покажет, что задача переоткрыта. Журнал покажет,
**на каком стыке** ошиблись, **почему** и **что поменяли**, чтобы не ошибиться так снова.

## Запись (`MX010`)

| Колонка | Правило |
|---|---|
| № | сквозной номер записи |
| Строка | `EX-NN`, которую вернули |
| Дата | `ДД.ММ.ГГГГ` |
| Кто вернул | проверяющий строки |
| Тип | из списка ниже |
| Что не так | факт расхождения: что ожидали по критерию, что получили |
| Корневая причина | из списка ниже |
| Действие | что делает поставщик |
| Повторная сдача | `ДД.ММ.ГГГГ` или `—`, пока не сдали |
| Урок | правка матрицы или чеклиста, которая предотвратит повтор; `не требуется` — с причиной |

**Тип несоответствия:** `Критерий не выполнен` · `Не тот результат` · `Не то место` ·
`Сорван срок` · `Неверный критерий` · `Стык не учтён`.

**Корневая причина:** `Исполнение` (сделали не так) · `Матрица` (строка или критерий были плохими) ·
`БФТ` (требование неполное или противоречивое) · `Коммуникация` (стороны поняли по-разному).

Строка со статусом `Возврат` без записи в журнале — `MX010`. Запись со строкой, которой нет в
матрице, — тоже.

## Урок возвращается в шаблон

Причина `Матрица` или `БФТ` — сигнал, что ошибся не исполнитель, а документ. Урок такой записи
становится пунктом чеклиста паузы или правкой критерия строки. Так Google и AWS растят свои
чеклисты запуска: каждый пункт оправдан реальным сбоем. При закрытии инициативы (`status: закрыта`)
уроки с причиной `Матрица` — кандидаты в `../examples/` и в правила навыка; решает PO.

## Риски стыков (`MX016`)

Только риски, которые PO подтвердил (тот же принцип, что гейт 21 БФТ: выдуманный риск дороже
пропущенного). Состояние — по ROAM из SAFe:

| Состояние | Значит |
|---|---|
| `Снят` | риск больше не актуален |
| `Взят` | у риска есть владелец, он им занимается |
| `Принят` | осознанно живём с риском, ничего не делаем |
| `Снижен` | меры приняты, остаточный риск приемлем |

Владелец — человек; пересмотр — дата.
